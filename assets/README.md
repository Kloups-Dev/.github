# Visuels Kloups Studio

Direction G.3 — Empreinte numérique.

- `banner.png` : bannière du profil, 2560 × 1120 px.
- `avatar.png` : symbole K simplifié, 512 × 512 px.
- `generate_assets.py` : source de génération (Python + Pillow).

Palette : encre #0E1014, ivoire #F7F4EB, cobalt #3155E7.
La bannière utilise les véritables fontes Satoshi Black, Medium et Regular de Fontshare (licence ITF Free Font License acceptée). Les fontes ne sont pas redistribuées ici.

Pour régénérer : `python generate_assets.py chemin/vers/Satoshi_Complete.zip`. Les exports sont produits dans un sous-dossier `assets`.

Le K est une première construction géométrique pour GitHub, à valider lors de la finalisation du logotype.
